# PHISHTRIAGE-Agentic-AI-Hackathon

Multi-agent phishing investigation Chrome extension. Specialized AI agents (forensic, vision, adversarial critic, threat memory) analyze reported emails, a deterministic engine calculates the risk score, and security analysts approve every action. Rules decide, agents investigate, humans approve.

Built with contributions to the Chrome extension interface and email input handling.

## Email Analysis Workflow

1. Receive a reported email.
2. Extract sender details, headers, content, and URLs.
3. Send the email for multi-agent investigation.
4. Calculate the risk score using the deterministic engine.
5. Display the findings for analyst review.
